# Spartacus's Island 🐾

A cosy 3D pirate pup adventure for the browser. Spartacus sails from island to island, eats magic fruits that give him powers, solves gentle puzzles and gathers a crew of animal friends. No enemies, no game over.

**Play:** https://keepitterron.github.io/spartacus-island/ (works offline once loaded; add it to your home screen to install).

Keyboard: WASD/arrows move, Space jumps, F acts, B barks, Q/E or drag to look. On phones: stick, Jump, Woof and the green action button.

## Develop

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:5173/spartacus-island/. Docs for adding levels and features are in [docs/](docs/README.md).
