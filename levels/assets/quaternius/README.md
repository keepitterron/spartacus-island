# Quaternius models (CC0)

Low-poly models by [Quaternius](https://quaternius.com), released as
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain, no attribution
required; credited here anyway). The .glb files came from the
[quaternius-showcase](https://github.com/trebeljahr/quaternius-showcase) mirror.

| Pack             | Source                                            | Models                                                                                                                            |
| ---------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Ultimate Nature  | https://quaternius.com/packs/ultimatenature.html  | BushBerries_1, CommonTree_1–3, Flowers, Grass, Lilypad, Plant_3, Rock_Moss_1, Rock_Moss_4, TreeStump_Moss, Willow_2, WoodLog_Moss |
| Simple Nature    | https://quaternius.com/packs/simplenature.html    | Tree1                                                                                                                             |
| Medieval Village | https://quaternius.com/packs/medievalvillage.html | Bags, Barrel, Bench_1, Bonfire_Lit, Crate, Well                                                                                   |
| Survival         | https://quaternius.com/packs/survival.html        | Tent                                                                                                                              |
| Ships            | https://quaternius.com/packs/ships.html           | Boat, Lifeboat                                                                                                                    |

These are the originals. `tools/levels/dress_test_island.py` imports them into a level's Library
collection, scaled and recoloured to the game's palette.
